## Чего проверить нельзя без человека

- **Подтверждение входа в боте.** Вход завершается, только когда человек нажмёт
  «Подтвердить вход» в Telegram. У нас нет доступа к чату бота на этого
  пользователя, поэтому переход `pending → confirmed` и получение
  `session_token` вживую не воспроизведены. Это граница протокола: `device_nonce`
  приходит ТОЛЬКО в чат бота (защита от login-CSRF, §2.1 контракта), и обойти её
  без человека нельзя.
- **Следствия того же:** живой список `/me` и загрузка `.ovpn` (они требуют
  валидной сессии), а также поднятие туннеля из живого профиля — не проверены
  вживую. Проверены кодом, тестами и ревью.
- **§3.3 (пропуск входа при живой сессии).** Подтверждён обратный случай:
  чистая установка (`pm clear`) ведёт на экран входа. Прямой случай (валидная
  сохранённая сессия → сразу на подключение) не воспроизведён, потому что
  валидной сессии получить нельзя.

## Наблюдения по ходу проверки

- **Инструментальная грабля (снова, при этой проверке):** `uiautomator dump
  /sdcard/x.xml` под Git Bash на Windows без `MSYS_NO_PATHCONV=1` пишет файл по
  пути `C:/Program Files/Git/sdcard/x.xml` и падает, а `cat` печатает пустоту —
  выглядит как «пустой экран приложения». Это ложная тревога, а не дефект
  приложения; переменную надо ставить на КАЖДУЮ adb-команду.
- **Activity пересоздаётся при уходе в Chrome** (системный лаунчер вместо
  Telegram на эмуляторе), поэтому стек навигации Compose (в `remember`) сбрасывается
  на вход. На реальном устройстве приложение не уходит в фон (Telegram
  открывается поверх), и путь выглядит иначе.
- **Отладка без сети была невозможна в один заход:** `ApiClient` не имеет
  OkHttp-логгера, поэтому тела ответов в logcat не видно. Наблюдать удалось по
  косвенным признакам — системному интенту с `deep_link` и смене состояния
  экрана на «Проверяем…».

## Вердикт

Клиентская сторона API подключена и работает: вход начинается по-настоящему,
экран с кодом из бота появился, опрос уходит. Полная сквозная проверка до
«подключено» требует одного шага руками — подтверждения в Telegram.
